## Що потрібно від власника

- Колекції в CRM: `curly-joy-recommends` (сторінка «Обрано Curly Joy»), за бажанням — новинки чи хіти; без цього теги карток показують лише знижку.
- `compareAtPrice` у CRM для акційних товарів — тоді з’являться % знижки й стара ціна.
- Групування варіантів (`productGroupId`) для товарів з різним ароматом чи кольором.
- Посилання Telegram/Viber, сайт розплідника, матеріали для «Про нас», файли логотипів платіжних систем.

## Перевірки

`npm run typecheck`, `npm run lint -- --max-warnings 0`, `npm test` (203/203).
У Chrome перевірено хедер, пошук із клавіатурою, каталог з фільтрами
й пагінацією, картку товару, додавання в кошик з картки й сторінки товару,
кошик (порожній, з прогресом, з безкоштовною доставкою), checkout і маску
телефону, B2B, «Улюблені», чернетку «Блог», мобільні ширини без
горизонтального переповнення. Тестові товари з локального кошика видалено.
Нижня панель покупки на телефоні: логіку появи перевірено у вкладці
1440 px, вигляд — у вузькому iframe. Production build, Safari, фізичні
телефони й сторінка успішного замовлення не перевірялися.
