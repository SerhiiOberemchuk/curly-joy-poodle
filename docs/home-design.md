# Головна сторінка

Джерело: https://curly-store.com.ua/summer-home-page — сайт власника, вказаний у `init.md`.

Відтворено основну композицію референсу: світла шапка з логотипом Curly Joy, повноширинний літній фотобанер, велика картка каталогу та дві сезонні картки, блок Elasto-fit, команда, цінності й фотогалерея. Літні товари та команда, присутні у вихідній сторінці, доступні і на desktop, і на mobile.

Палітра: білий, `#ece6e4`, `#ededf0`, текст `#282828`, акцент `#ff4259`. Шрифт Montserrat через `next/font`. На мобільних текст банера розташований над собакою, щоб не перекривати її обличчя.

Фото та логотипи скопійовані з референсу й оптимізовані до локальних WebP. Список вихідних URL — `public/images/reference/sources.json`. Зображення віддаються через `next/image`; зовнішній CDN під час перегляду не потрібен. Дані головної — `src/features/home/content.ts`. Посилання ведуть на локальний каталог, колекції, товари та розміри; галерея — на Instagram власника.

Шість літніх товарів використовують ті самі фото в каталозі, на сторінці товару й у кошику. Решта каталогу поки має попередні зображення-заглушки. Назви, ціни, залишки й оплата залишаються на поточному джерелі даних; це оновлення дизайну, а не синхронізація каталогу з оригіналом.

Головна складається із Server Components. Персональний індикатор кошика зберігає `Suspense`, каталог — `use cache`, мутації — Server Actions. Нових залежностей у проєкті немає.
